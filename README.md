# JHU COVID-19 Predictive Analysis & Health Commodities Forecasting (Orange Data Mining)

Predictive analysis and time-series forecasting workflows built using **Orange Data Mining**, analyzing Johns Hopkins University (JHU) COVID-19 datasets alongside human development index (HDI) indicators and emergency health commodity quantification.

## Contents

- `COVID19_JHUHDI_20241211.ows` — Orange Data Mining workflow file (`.ows`) containing data preprocessing, feature correlation, clustering, and predictive modeling pipelines for JHU COVID-19 & HDI data.
- `MSDS500_ForecastingAlgorithmsQuantificationofHealthCommodities_Emergency_20241225.pdf` — Research manuscript / report on forecasting algorithms and optimal resource allocation of health commodities during emergencies.

## Requirements & Usage

1. Install [Orange Data Mining](https://orangedatamining.com/) (with the **Time Series** add-on enabled).
2. Open `COVID19_JHUHDI_20241211.ows` in Orange Data Mining to inspect and execute the visual workflow.
